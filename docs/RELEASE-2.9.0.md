# Neko Craft Launcher 2.9.0

> 这一版主要是一次「把界面做整」的大修：从零散补丁变成统一的设计语言，同时把几个长期存在的
> 交互/渲染缺陷连根拔掉。共 168 个提交。

## 安装包

| 文件 | 说明 |
|---|---|
| `NekoCraftLauncher-2.9.0.exe` | **安装版**：双击安装，可选目录，自动创建开始菜单与桌面快捷方式（按用户安装，无需管理员） |
| `NekoCraftLauncher-2.9.0-win64.zip` | 免安装版，解压后双击 `NekoCraftLauncher.exe` |

- 系统要求：Windows 10/11 x64
- 内置 Java 运行时，不需要另外装 Java
- 首次运行若出现 SmartScreen 提示，选「更多信息 → 仍要运行」（构建产物未做代码签名）

## UI 大改

- **统一设计语言**：卡片、按钮、输入框、列表行统一圆角与描边；组件样式拆到 `components.css`，
  颜色全部走 `-app-*` 主题变量，深/浅两套主题都可用。
- **一键体检变成独立页面**：带返回键、总览头、九项检查、可点击告警行，以及完整性检查 / 复制 /
  导出报告三个动作。
- **启动页重排**：账户信息块垂直居中、底部按钮固定；统计卡改为三张（启动记录 / 最近一次启动 /
  累计游玩）且可点击跳转；历史记录卡补「查看全部记录」。
- **模组管理重做**：单列集成式列表，顶部搜索实时过滤，工具栏（打开文件夹 / 从文件安装 /
  下载新资源 / 全选 / 导出信息 / 模组关系）一行排布；「下载新资源」进入独立的在线模组页。
  每行读取 jar 内 `fabric.mod.json` / `mods.toml`，显示名称、版本、加载器、大小与描述，
  悬停可看完整路径。
- **启动顾问页有内容了**：稳定性统计（次数 / 崩溃 / 成功率 / 平均准备）、最近 5 条异常、
  打开日志与崩溃目录、一键体检。
- **实例设置治理**：删掉顶部无用的实例胶囊行；左侧导航按「选中 > 悬停 > 普通」统一重绘；
  修改页的保存按钮归位到卡片内；表单/高级管理按钮有了可见底色；所有按钮都有悬停反馈。
- **动效统一为线性**，并支持在设置里关闭动画（关闭后悬停提亮也会一起停用）。

## 重要修复

| 问题 | 原因 |
|---|---|
| 安装页整页空白 | `InstallerPage.build()` 从未把头部和卡片加进 `panel`，返回了空 VBox |
| 实例设置点完导航旧项不还原 | 导航登记表 `navBox` 是个未入场景的空 VBox，切换时遍历到空列表 |
| 切换页面「变色延迟」 | 先上色再同步构建页面，最慢 109ms，重绘被阻塞 |
| 右下角红字乱码 | telemetry 指定了机器上不存在的等宽字体，被 fallback 成符号字体 |
| 退出弹窗按钮没颜色 | `.btn-danger/.btn-cyan` 只写在 `.dialog-pane` 作用域下，应用内弹窗命中不到 |
| AI 面板「没有展开」 | `ConsoleContainer` 只改 maxHeight 没设 `VBox.setVgrow`，聊天区永远停在 140px |
| 圆角批量修复 261 个 | `StyleRepair` 连隐藏页面一起遍历，下载页 40 个结果单元被整批补描边 |
| 列表图标是虚线转圈 | 图标加载中显示 `ProgressIndicator`，改为首字母占位，图到了再替换 |
